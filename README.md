# Cinelista: receitas de Next JS

Receitas de Programação Web com Next JS (13 a 23), implementadas passo a passo
num mesmo projeto: um catálogo de filmes chamado Cinelista.

## Receitas

- [x] 13: Aplicação Next JS do zero (rotas e páginas)
- [x] 14: Componentes e props
- [x] 15: Layout e Link
- [x] 16: Server component e API externa (OMDb)
- [x] 17: Formulário com Form
- [ ] 18: Client component e useState
- [ ] 19: API própria (route.js)
- [ ] 20: Server actions
- [ ] 21: Rotas dinâmicas e geração estática
- [ ] 22 (opcional): Banco de dados MySQL
- [ ] 23 (opcional): API do banco e página com SWR

## Como rodar

1. npm install
2. Crie o arquivo .env.local com a sua chave do OMDb (modelo em .env.example)
3. npm run dev

Abra http://localhost:3000
